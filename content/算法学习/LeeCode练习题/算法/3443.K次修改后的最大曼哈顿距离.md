### 问题概述:
给你一个由字符 `'N'`、`'S'`、`'E'` 和 `'W'` 组成的字符串 `s`，其中 `s[i]` 表示在无限网格中的移动操作：

- `'N'`：向北移动 1 个单位。
- `'S'`：向南移动 1 个单位。
- `'E'`：向东移动 1 个单位。
- `'W'`：向西移动 1 个单位。

初始时，你位于原点 `(0, 0)`。你 **最多** 可以修改 `k` 个字符为任意四个方向之一。

请找出在 **按顺序** 执行所有移动操作过程中的 **任意时刻** ，所能达到的离原点的 **最大曼哈顿距离** 。

**曼哈顿距离** 定义为两个坐标点 `(xi, yi)` 和 `(xj, yj)` 的==横向距离绝对值与纵向距离绝对值之和==，即 `|xi - xj| + |yi - yj|`。

**示例 1：**

**输入：s = "NWSE", k = 1
输出：3
解释:

将 `s[2]` 从 `'S'` 改为 `'N'` ，字符串 `s` 变为 `"NWNE"` 。

|移动操作|位置 (x, y)|曼哈顿距离|最大值|
|---|---|---|---|
|s[0] == 'N'|(0, 1)|0 + 1 = 1|1|
|s[1] == 'W'|(-1, 1)|1 + 1 = 2|2|
|s[2] == 'N'|(-1, 2)|1 + 2 = 3|3|
|s[3] == 'E'|(0, 2)|0 + 2 = 2|3|

执行移动操作过程中，距离原点的最大曼哈顿距离是 3 。

**示例 2：**

**输入：s = "NSWWEW", k = 3
输出：6
解释：

将 `s[1]` 从 `'S'` 改为 `'N'` ，将 `s[4]` 从 `'E'` 改为 `'W'` 。字符串 `s` 变为 `"NNWWWW"` 。

执行移动操作过程中，距离原点的最大曼哈顿距离是 6 


---
### 解题思路:
这道题的目标是求最大的曼哈顿距离,我们需要分别在水平和竖直方向上的最大距离(正数)然后相加方能得到最大的曼哈顿距离-->需要最大化 |x| + |y|
在移动时,有两种情况:
- 同向修改(如W修改为E),那么此时的补偿值为2(最大)
- 异向修改(如W修改为N),那么此时的补偿值为1(最小)
为了能够获得最大的x/y的值,我们最好采用同向修改的方案使得求得的结果最大化.
---
### 题解:贪心策略

#### 法1:通过模拟坐标以及反向补偿解决

```Java
public class MaxDistance {  
    public int maxDistance(String s, int k) {  
        int maxCorrection = k * 2;  // 最多能弥补的反向步数（每次修改能提升2距离）  
        int x = 0;  
        int y = 0;  
        int ans = 0;  
        // 原始移动  
        for (int i = 0; i < s.length(); i++){  
            switch (s.charAt(i)){  
                case 'N':  
                    y++;  
                    break;  
                case 'S':  
                    y--;  
                    break;  
                case 'E':  
                    x--;  
                    break;  
                case 'W':  
                    x++;  
                    break;  
            }  
            //当前的曼哈顿距离  
            int currDistance = Math.abs(x) + Math.abs(y);  
            ans = Math.max(ans, Math.min(i+1,currDistance+maxCorrection));  
  
        }  
        return ans;  
    }  
}
```
1. **初始化**​：`x = 0`，`y = 0`，`ans = 0`。
2. ​**遍历字符串**​：
    - 根据当前字符更新 `x` 或 `y`。
    - 计算当前曼哈顿距离 `|x| + |y|`。
    - 使用贪心策略计算最大可能的曼哈顿距离：
        - 每次同向修改可以增加 2 单位距离，因此最多可以增加 `k * 2`。
        - 当前最大曼哈顿距离为 `min(原始距离 + k * 2, 已移动步数)`（因为最多只能修改 `k` 个字符）。
3. ​**返回结果**​：`ans` 是遍历过程中的最大曼哈顿距离。

#### 法2:通过字符计数来代替坐标模拟

```Java
```java
class Solution {
    private int len;

    public int maxDistance(String s, int k) {
        int res = 0;
        int[] cnt = new int['X']; // 'W' + 1 = 'X'
        char[] chars = s.toCharArray();
        for (char ch : chars) {
            cnt[ch]++;
            this.len = k;
            res = Math.max(res,
                    this.f(cnt['N'], cnt['S']) + this.f(cnt['E'], cnt['W']));
        }
        return res;
    }
//函数f-->计算某个方向的最大净收益
//a:正向步数,b:反向步数
    int f(int a, int b) {
        int d = Math.min(a, Math.min(b, this.len));
        this.len -= d;
        return Math.abs(a - b) + d * 2;
    }
}
```

1. ​**初始化**​：`cnt` 数组统计 `'N'`、`'S'`、`'E'`、`'W'` 的数量。
2. ​**遍历字符串**​：
    - 更新 `cnt`。
    - 计算水平和垂直方向的最大净收益：
        - 对于 `'N'` 和 `'S'`，最大净收益为 `|cnt['N'] - cnt['S']| + min(cnt['N'], cnt['S'], k) * 2`。
        - 类似地计算 `'E'` 和 `'W'` 的最大净收益。
    - 更新 `k`：每次使用同向修改会消耗 `k`。
3. ​**返回结果**​：水平和垂直方向的最大净收益之和。

- **时间复杂度**​：`O(n)`，其中 `n` 是字符串长度。只需遍历字符串一次。
- ​**空间复杂度**​：`O(1)`，仅使用常数空间。

- `k = 0`：无法修改任何字符，直接计算原始移动的曼哈顿距离。
- `k >= n`：可以修改所有字符，最大曼哈顿距离为 `n`（全部同向移动）。
- 字符串为空：直接返回 0。

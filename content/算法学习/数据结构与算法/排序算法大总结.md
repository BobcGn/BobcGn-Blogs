# 排序算法大总结

学完了数据结构的排序后,我们开始重新审视一下我们所学过的所有排序算法,并总结他们各自的优劣

在此,我们将对链表进行操作

### 首先,先创建好链表,并进行一些基本的操作-->插入元素,获取相应索引的结点

```C++
//链表结点类
class list_nodes{
public:
    list_nodes*pNext;
    int data;
    list_nodes(int val) : data(val) , pNext(nullptr){}
};
//链表类
class ArrayList{
private:
    list_nodes *pHead;
public:
    //构造以及析构函数
    ArrayList() : pHead(nullptr){}
    ~ArrayList(){
        list_nodes *curr = pHead;
        while (curr){
            list_nodes *next = curr->pNext;
            delete curr;
            curr = next;
        }
    }
    //插入数据(尾插)
    void Insert_Data(int val){
        list_node *pNew = new list_nodes(val);
        if(!pHead){
            pHead = pNew;
        }
        else{
            list_nodes *curr = pHead;
            //寻找尾部结点
            while(curr->pNext){
                curr = curr->pNext;
            }
            //插入结点
            curr->pNext = pNew;
        }
    }
    
    //获取链表长度
    int getLength()const{
        int length = 0;
        list_nodes *curr = pHead;
        while (curr){
            curr = curr->pNext;
            length++;
        }
        return length;
    }
    
    //获取对应索引的结点
    list_nodes *getNodeAt(int index){
        list_nodes *curr = pHead;
        for(int i = 0 ; i<getLength() ; i++){
            curr = curr->pNext;
        }
        return curr;
    }
    
    //输出链表
    void Print_List(){
        if(!pHead) return;
        list_nodes *curr = pHead;
        while(curr){
            cout << curr->data <<" ";
            curr = curr->pNext;
        }
        cout << endl;
    }
};
```



## 1.交换排序

### 平均时间复杂度O(n log n),最坏情况下时间复杂度为O(n²).

### 空间复杂度平均O(n log n),最坏O(n).

### 稳定性:不稳定

从最开始写C语言的时候就开始讲,最最基础的排序就是将从第一个元素开始,依次和后面的作比较,如果是逆序就交换

如序列[2,3,1,4],先以2为基准,依次与后面的元素作比较并交换-->[1,3,2,4] ; 再以3(第二个元素)作为基准,与后面的元素比较,以此类推-->[1,2,3,4]

根据如上规律,我们就可以来编写代码

```c++
//交换排序
void Exchange_Sort(){
    //空表判定
    if(!pHead || !pHead->pNext) return;
    //从头结点开始
    list_nodes *curr = pHead;
    while(curr){
        list_nodes *next = curr->pNext;
        while(next){
            //每次将相邻元素比较,如果是逆序,则交换
            if(curr->data > next->data){
            	swap(curr->data , next->data)
        	}
        	next = next->next
        }
        curr = curr->pNext;
    }
}
```



## 2.冒泡排序

### 平均时间复杂度O(n²)

### 空间复杂度O(1)

### 稳定性:稳定

### 但是效率低,不适合大规模的数据

冒泡排序是我们学习C语言基础时候接触的最多的排序算法,原理也很简单:从头到尾依次比较相邻元素(1 VS 2 -->是否交换--> 2 VS 3-->是否交换......),使大数交换到序列末尾,小数交换到序列前端.如序列[5,3,8,4,2]

第一轮:[5,3,8,4,2]-->(5 VS 3-->交换)-->[3,5,8,4,2]-->(5 VS 8-->不交换)-->(8 VS 4-->交换)-->[3,5,4,8,2]-->(8 VS 2-->交换)-->[3,5,4,2,8] (8已经就位)

第二轮:(3 VS 5-->不交换)-->(5 VS 4-->交换)-->[3,4,5,2,8]-->(5 VS 2-->交换)-->[3,4,2,5,8] (5已经就位)

第三轮:(3 VS 4-->不交换)-->(4 VS 2-->交换)-->[3,2,4,5,8] (4已就位)

第四轮:(3 VS 2-->交换)-->[2,3,4,5,8] (3已就位)

至此,所有交换完成.可以发现,每轮冒泡都将较大的数字换至序列末尾

根据规律来编写代码:

```C++
//冒泡排序
void Bubble_Sort(){
    //空表判定
    if(!pHead || !pHead->pNext) return;
    
    //临时指针-->ptr1进行遍历,ptr2记录未排序部分的末尾(边界)
    list_nodes *ptr1, *ptr2=nullptr;
    bool swapped;		//判断是否交换
    do{
        swapped = false;
        ptr1 = pHead;
        while(ptr1->next != ptr2){
            if(ptr1->data > ptr1->pNext->data){
                swap(ptr1->data , ptr1->pNext->data);
                swapped = true;
            }
            ptr1 = ptr1->pNext;
        }
        ptr2 = ptr1;
    }
    //循环条件:当还有元素能执行交换时保持循环
    while(swapped)
}
```



## 3.选择排序

### 时间复杂度O(n²) (所有情况) ,

### 空间复杂度O(1) .

###  稳定性:不稳定

### 效率低,不适合大规模数据

选择排序是通过将序列分为两部分-->已排序(初始为空)和未排序(初始为整个序列),然后将未排序序列的最大/最小值依次置入已排序序列的末尾/前端,相比于冒泡排序,减少了比较次数来节省时间

例:初始序列为[64,25,12,22,11]-->找到最小元素(11)-->交换64和11-->[11,25,12,22,64]-->找除了11以外最小(第二小)的元素(12)-->交换25和12->[11,12,25,22,64]-->继续找第三小的元素(22)-->交换25和22-->[11,12,22,25,64]-->排序完毕

```C++
void Choice_Sort(){
    //空表判断
    if(!pHead || !pHead->pNext) return;
    //已排序序列(初始为空) 和 未排序序列(初始为整个链表)
    list_nodes *sorted = nullptr;
    list_nodes *currr = pHead;
    while(curr){
        //未排序序列中的最小元素(初始为头结点的值)
        list_nodes *min = curr;
        list_nodes *r = curr->pNext;
        while(r){
            //如果min的值大于r的值,更新min的值
            if(min->data > r->data){
                min = r;
            }
            r = r->pNext;
        }
        //找到最小元素并交换
        swap(min->data , curr->data);
    }
}
```



## 4.插入排序

### 时间复杂度最好(已有序时)O(n),平均/最坏:O(n²)

### 稳定性:稳定

### 优缺点:对小规模数据高效但是大规模数据效率低

插入排序,类似于我们平时打牌:假如我要摸5张牌,[3,Q,K,6,10] (所有牌初始都不知道值)

我们开始逐步拿牌-->3-->[3]-->Q-->[3,Q]-->K-->[3,Q,K]-->6-->[3,6,Q,K]-->10-->[3,6,10,Q,K]

我们发现,前三张牌都是顺序,所以顺序加入序列末尾即可,但是摸到第四张的时候,我们就应该在序列中找到合适的插入位置并将这张牌插入到正确的位置,第五张牌同理.

所以,插入排序的核心就在于-->找到合适的插入位置并将结点插入到序列中

```C++
void Insertion_Sort(){
    //空表判定
    if(!pHead || !pHead->pNext) return;
    //创建哨兵结点
    list_nodes dummy(0);
    list_nodes *curr = pHead;
    dummy.pNext = nullptr;
    //外层循环：逐个取出未排序节点。
    while(curr){
        //curr的前驱和后继结点
        list_nodes *pPrev = &dummy;
        list_nodes *pNext = curr->next;
        //内层循环：在已排序部分中找到插入位置并完成插入。
        while(pPrev->pNext && pPrev->pNext->data < curr->data){
            pPrev = pPrev->pNext;
        }
        curr->pNext = pPrev->pNext;  // curr 接管 pPrev 的后继
        pPrev->pNext = curr;		// 将 curr 插入到 pPrev 之后
        curr = pNext;
    }
    pHead = dummy.pNext;
}
```



## 5.希尔排序

### 时间复杂度:平均:O(n log n) ~ O(n²)(取决于gap),最好:O(n log n). 

### 空间复杂度O(1)

### 稳定性:不稳定

### gap的实际大小会对性能有不同的影响

通过一个整数gap来改良插入排序,通过gap来将序列分为若干组,每个组内进行排序,然后逐步缩小gap直至gap为1

如序列[8,3,5,1,4,2,7,6],gap的初值为序列长度的一半-->gap=4

每4个数为一组来分割序列-->[8,4],[3,2],[5,7],[1,6]-->将逆序的子序列进行排序-->[4,8],[2,3],[5,7],[1,6]-->排序后的序列-->[4,2,5,1,8,3,7,6]-->将gap/=2 --> gap=2

每2个数为一组分割序列-->[4,5,8,7],[2,1,3,6]-->将逆序的子序列排序-->[4,5,7,8],[1,2,3,6]-->排序后的序列-->[4,1,5,2,7,3,8,6]-->gap/=2 --> gap=1

当gap为1时,就是我们熟悉的插入排序了.通过这个过程,我们也不难发现,插入排序其实是gap恒等于1时的希尔排序,而希尔排序是插入排序的一般情况

```c++
void Shell_Sort(){
    if(!pHead || !pHead->pNext) return;
    //获取链表长度
    int len = getLength();
    //外层循环：控制增量 gap，逐步细化分组
    for(int gap = len/2 ; gap>=1 ; gap/2){
        //中层循环：遍历每个子序列的起始点
        for(int i = gap ; i < len ; i++){
            //用tmp存储索引为i的结点数据
            int tmp = getNodeAt(i)->data;
            int j;
            //内层循环:对子序列插入排序
            for(j = i ; j>=gap && getNodeAt(j-gap)->data >tmp ; j -= gap){
                getNodeAt(j)->data = getNodeAt(j-gap);//更新j索引的值
            }
            getNodeAt(j)->data = tmp;
        }
    }
}
```



## 6.归并排序

### 时间复杂度(任意情况):O(n log n)

### 空间复杂度:O(n)

### 稳定性:稳定

### 优缺点:适合大规模数据,但是空间占用较大

归并排序是典型的体现**分治思想**的高效排序算法-->**分**:将序列递归分割为原来的一半,直至每个子序列只有一个元素(自然有序) ; **合**(治):然后把已排序的序列进行合并,直至所有的序列合并完毕

如序列[38,27,43,3,9,82,10]-->分割-->[38,27,43,3] , [9,82,10]-->分割-->[38,27] , [43,3] , [9,82] ,[10]-->分割-->[38],[27],[43],[3],[9],[82],[10]-->合并并排序-->[27,38] , [3,43] , [9,82] , [10]-->合并并排序-->[3,27,38,43] , [9,10,82]-->合并并排序-->

[3,9,10,27,38,43,82]

```C++

        slow = slow->pNext;
        fast = fast->pNext->pNext;

    slow->pNext = nullptr;
    //递归排序左右两部分
    list_nodes *left = Merge_Sort_Helper(head);
    list_nodes *righr = Merge_Sort_Helper(mid);
    //返回合并且排序后的链表
    return merge(left,right);
}
//合并两个有序链表的函数
list_nodes *merge(list_nodes *left , list_nodes*right){
    list_nodes dummy(0);
    list_nodes *tail = &dummy;
    while(left && right){
        if(left->data < right->data){
            tail->pNext = left;
            left = left->pNext;
        }
        else{
            tail->pNext = right;
            right = right->pNext;
        }
        tail = tail->pNext;
    }
    tail->pNext = left ? left : right;
    return dummy.pNext;
}
```



## 7.快速排序

### 时间复杂度:平均/最好:O(n log n),最坏:O(n²). 

### 空间复杂度:平均:O(log n),最坏(极端不平衡时):O(n)

### 稳定性:不稳定

### 优缺点:平均性能最好,但需要优化最坏情况

快速排序也是一种体现了==分治思想==的一种排序算法-->选取序列中的一个元素作为基准(pivot),将序列中除了pivot的所有元素分割为两部分-->左序列(大于pivot)和右序列(小于pivot)-->对左右序列重复上述步骤进行排序-->最后合并所有的元素

如序列[46,74,53,14,26,38,86,65,27,34]-->以第一个元素(46)为基准分割其余元素-->less[14,26,38,27,34] , greater[74,53,86,65]-->重复以上操作对两个子序列进行排序-->less[14,26,27,34,38] , greater[53,65,74,86]-->合并所有元素-->[14,26,27,34,38,46,53,65,74,86

]

```C++
void Quick_Sort(){
    pHead = Quick_Sort_Helper(pHead);
}
list_nodes *Quick_Sort_Helper(list_nodes *head){
    //空表判定
    if(!pHead || !pHead->pNext) return;
    
    //选择头结点作为基准
    list_nodes *pivot = pHead;
    list_nodes *less = new list_nodes(0),*greater = new list_nodes(0);
    list_nodes *lessTail = less , *greaterTail = greater;
    list_nodes *curr = pHead->pNext;
    //分割链表
    while(curr){
        //小于基准元素的置于less序列
        if(curr->data < pivot->data){
            lessTail->pNext = curr;
            lessTail = lessTail->pNext;
        }
        //大于基准元素的置于greater序列
        else{
            greaterTail->pNext = curr;
            greaterTail = greaterTail->pNext;
        }
        curr = curr->pNext;
    }
    //分割完毕后将两个序列的尾指针置空
    lessTail->pNext = greaterTail->pNext = nullptr;
    //递归排序左右两部分
    list_nodes *sortedLess = Quick_Sort_Helper(less->pNext);
    list_nodes *sortedGreater = Quick_Sort_Helper(greater->pNext);
    
    //释放临时结点的内存
    delete less;
    delete greater;
    
    //合并-->sortedLess + pivot + sortedGreater
    if(sortedLess){
        list_nodes *tail = sortedLess;
        while(tail->pNext){
            tail = tail->pNext;
        }
        tail->pNext = pivot;
    }
    pivot->pNext = sortedGreater;
    return sortedLess ? sortedLess : pivot;
}
```



## 8.堆排序

### 时间复杂度(所有情况):O(n log n)

### 空间复杂度:O(1)

### 稳定性:不稳定

### 优缺点:原地排序且最坏情况仍然高效,但是缓存不友好

堆排序的关键在于使用"堆"这个数据结构.首先我们来介绍一下堆-->首先声明,堆在这里指的是一种数据结构,而非垃圾的收集存储.

首先,我们需要建立一个二叉堆--一个近似完全的二叉树.但不同于二叉搜索树的左小右大的规律,二叉堆的每个结点的子节点都会比它的值要小(大).而二叉堆又可以分为-->最大堆(大根堆,大顶堆)和最小堆(小跟堆,小顶堆).其中,大根堆满足除了根节点以外的结点都满足子节点小于其父结点,小跟堆反之.

在堆排序中,我们将建立一个大根堆(小跟堆在优先队列中会使用)来帮助我们进行排序.但是我们的初始序列并不是严格有序的,我们建立好堆之后,还需要让大的元素上浮,小的元素下潜.

##### 排序的过程通过反复取出堆顶元素并调整堆来进行:

1.  交换堆顶元素和末尾元素-->将堆顶元素和当前未排序的部分的最后一个元素交换
2.  排除已排序的最大值,并减小堆的大小
3.  对新的堆顶元素进行下潜操作
4.  重复以上步骤直至只剩一个元素,排序结束

如序列[4,10,3,5,1],先建立大顶堆-->[10,5,3,4,1]-->交换10和1-->[1,5,3,4,10]-->调整堆-->[5,4,3,1,10]-->交换5和1-->[1,4,3,5,10]-->调整堆-->[4,1,3,5,10]-->交换4和1-->[1,4,3,5,10]-->调整堆-->[4,1,3,5,10]-->交换4和3-->[3,1,4,5,10]-->无需调整-->交换3和1-->[1,3,4,5,10]

排序完毕

```C++ 
void Heap_Sort(){
    //空表判定
    if(!pHead || !pHead->pNext) return;
    
    int len = getLength();
    //构造大顶堆
    for(int i = len/2-1 ; i>=0 ; i--){
        heapify(length,i);
    }
    //逐个提取堆顶元素
    for(int i = len-1 ; i>0 ; i--){
        swap(getNodeAt(0)->data , getNodeAt(i)->data);
        heapify(i,0);
    }
}

//构建大顶堆-->参数n:元素个数 , 参数i:当前需要堆化的节点索引
void heapify(int n , int i){
    int largest = i;	//初始化最大值为当前索引
    int left = 2*i+1;
    int right = 2*i+2;
    
    //如果左结点存在且大于最大值
    if(left < n && getNodeAt(left)->data > getNodeAt(largest)->data){
        largest = left;
    }
    //如果右结点存在且大于最大值
    if(right < n && getNodeAt(right)->data > getNodeAt(largest)->data){
        largest = right;
    }
    //如果最大值不是当前结点,交换当前节点与最大值节点的值
    if(largest != i){
        swap(getNodeAt(i)->data , getNodeAt(largest)->data);
        heapify(n,largest);
    }
}
```



## 9.桶排序

### 时间复杂度:最好(数据均匀分布):O(n+k),最坏(所有数据集中在一个桶内):O(n²)

### 空间复杂度:O(n+k)

### 稳定性:稳定(取决于桶内的排序算法)

### 优缺点:线性时间,但是依赖数据分布,空间占用大

桶排序是一种非比较类型的排序算法,适用于**均匀分布**的数据,通常根据某种规律将序列中所有元素分到有限个桶中,每个桶内进行排序(通常使用别的排序算法),最后再将所有桶按顺序合并.

分桶的依据是根据序列中的最大值和最小值来分.如序列[29,25,3,49,9,37,21,43],假设桶的数量k=5

最大值-->49,最小值-->3,那么每个桶的范围就应该是(49-3)/5≈9.2

即桶0:[3,12) , 桶1:[12,21) , 桶2:[21,30) , 桶3:[30,39) , 桶4:[39,48) , 桶5:[48,56)

分完桶之后将元素按照范围置入桶中-->桶0:[3,9] , 桶1[ ], 桶2:[21,25,29] , 桶3[37] , 桶4[43] , 桶5[49]

将每个桶的内部进行排序(如插入排序)后进行合并即可-->[3,9,21,25,29,37,43,49]

```C++
void Bucket_Sort(){
    //空表判定
    if(!pHead || !pHead->pNext) return;
    
    //找到最大值和最小值
    int minVal = pHead->data;
    int maxVal = pHead->data;
    list_nodes *curr = pHead->pNext;
    while(curr){
        if(curr->data < minVal) minVal = curr->data;
        if(curr->data > maxVal) maxVal = curr->data;
        curr = curr->pNext;
    }
    //若所有元素相同则无需排序
    if(minVal == maxVal) return;
    
    //动态计算桶的数量
    int bucketCount - min(20,max(5,(int)sqrt(getLength())));
    vector<vector<int>>buckets(bucketCount);
    //将元素分配到桶中
    curr = pHead;
    while(curr){
        int bucketIndex = ((long long)curr->data-minVal)*(bucketCount-1)/(maxVal-minVal);
        buckets[bucketIndex].push_back(curr->data);
        curr = curr->pNext;
    }
    //对每个桶进行排序
    for(auto& bucket : buckets){
        sort(bucket.begin() , bucket.end());
    }
    
    //合并所有桶
    curr = pHead;
    for(const auto& bucket : buckets){
        for(int val : bucket){
            curr->data = val;
            curr = curr->pNext;
        }
    }
}
```



## 10.计数排序(只适用于整数排序!!)

### 时间复杂度:O(n+k)

### 空间复杂度:O(n+k)

### 稳定性:稳定

### 优缺点:非比较排序,速度快,但仅适用于整数,数据范围大的时候会造成很大的空间浪费

计数排序同样是一种非比较类型的排序算法,它通过统计序列中每个元素出现的次数根据统计结果依次输出元素.适用于数据范围有限且分布密集的整数序列.

如:序列[4,2,2,8,3,3,1]-->先统计从0到序列最大值内的所有元素出现的次数-->count=[0,1,2,2,1,0,0,0,1]-->重组链表-->[1,2,2,3,3,4,8]

```C++
void Count_Sort(){
    //空表判定
    if(!pHead || !pHead->pNext) return;
    
    //找最小值和最大值
    int min = pHead->data;
    int max = pHead->data;
    list_nodes* current = pHead->pNext;
    while (current) {
        if (current->data < min) min = current->data;
        if (current->data > max) max = current->data;
        current = current->pNext;
    }
    
    //创建计数数组并初始化
    int range = max-min+1;
    int *count = new int[range]();
    
    //统计每个元素出现的次数
    current = pHead;
    while(current){
        count[current->data - min]++;
        current = current->pNext;
    }
    
    //根据计数数组重组链表
    current = pHead;
    //外层循环:按顺序遍历所有可能的值
    for(int i = 0; i<range ; i++){
        //内层循环:处理当前值的所有出现次数
        while(count[i]>0){
            //将当前节点的数据设置为i+min-->还原实际值
            current->data = i+min;
            current = current->pNext;
            count[i]--;
        }
    }
    //释放计数数组内存
    delete[] count;
}
```



## 11.基数排序

### 时间复杂度:O(d*(n+k))-->d为位数,k为基数

### 空间复杂度:O(n+k)

### 稳定性:稳定

### 优缺点:适用于整数或字符串,只花费线性时间.但是依赖位数,浮点不适用.

基数排序也是一种非比较型的整数排序算法,通过逐位(逐关键字)分配和收集来实现排序.

如序列[170,45,75,90,802,24,2,66],先找到最大的数字的位数-->3,确定接下来我们要执行三轮比较

1.个位: 0:[90,170] 2:[802,2] 4:[24] 5:[45,75] 6:[66] -->[90,170,802,2,24,45,75,66]

2.十位: 0:[802,2]  2:[24]  4:[45]  6:[66]  7:[170,75]  9:[90] -->[802,2,24,45,66,170,75,90]

3.百位: 0:[2,24,45,66,75,90]  1:[170]  8:[802] -->[2,24,45,66,75,90,170,802]

排序完毕

```C++
void Radix_Sort(){
    //空表判定
    if(!pHead || !pHead->pNext) return;
    //找到最大值的最大位数
    int max = pHead->data;
    list_nodes *curr = pHead->pNext;
    while(curr){
        if(curr->data > max) max = curr->data;
        curr = curr->pNext;
    }
    //计算最大位数
    int maxDigit = 1;
    while(max/=10) maxDigit++;
    
    //创建10个桶(0~9)
    vector<list_nodes*> buckets[10];
    //按位进行排序
    for(int digit = 0 ; digit < maxDigit ; digit++){
        curr = pHead;
        while(curr){
            int bucketIndex = (curr->data / (int)pow(10 , digit))%10;
            buckets[bucketIndex].push_back(curr);
            curr = curr->pNext;
        }
    }
    
    //重新连接链表
    list_nodes *newHead = nullptr;
    list_nodes *tail = nullptr;
    for(int i=0 ; i<10 ; i++){
        for(auto node : buckets[i]){
            if(!newHead){
                newHead = node;
                tail = node;
            }
            else{
                tail->pNext = node;
                tail = node;
            }
        }
        tail->pNext = nullptr;
        pHead = newHead;
    }
}
```
